# L'Atelier de Marie — ébauche de landing page

Site Next.js de démonstration, créé directement dans le dossier `creations-marie`.

## Lancer en local

```bash
npm install
npm run dev
```

Ouvrir ensuite [http://localhost:3000](http://localhost:3000).

## Remplacer le contenu

- Textes, prix provisoires et coordonnées fictives : `content/siteContent.js`.
- Les trois photos fictives de chaque catégorie sont dans `public/images/placeholders/`. Remplacer un fichier en gardant son nom, ou modifier sa liste `images` dans `content/siteContent.js`.
- Couleurs et mise en page : `app/globals.css`.

Les prix sont seulement indicatifs sur cette vitrine ; le site ne contient ni panier ni paiement.
